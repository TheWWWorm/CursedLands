Cursed Lands: RTX 30 package withdrawn / Пакет RTX 30 отозван / RTX-30-Paket zurückgezogen

ENGLISH
The optional RTX 30 package was permanently withdrawn on 2026-10-24 because
redistribution rights for its modified NVIDIA components were unresolved.
It will not be published again. Use the ordinary Windows download.
To remove the mod from an existing installation, close the game and remove
winmm.dll, dlssg_sm86.ini and the dlssg_sm86 folder from beside CursedLands.exe.
Do not remove similarly named files from Windows system folders.

РУССКИЙ
Дополнительный пакет RTX 30 окончательно отозван 24.10.2026: права на
распространение изменённых компонентов NVIDIA не были подтверждены.
Пакет больше не будет публиковаться. Используйте обычную сборку для Windows.
Чтобы удалить мод из установленной игры, закройте игру и удалите winmm.dll,
dlssg_sm86.ini и папку dlssg_sm86 рядом с CursedLands.exe.
Не удаляйте одноимённые файлы из системных папок Windows.

DEUTSCH
Das optionale RTX-30-Paket wurde am 24.10.2026 dauerhaft zurückgezogen, weil
die Weiterverbreitungsrechte für seine veränderten NVIDIA-Komponenten ungeklärt
waren. Es wird nicht erneut veröffentlicht. Verwenden Sie den regulären
Windows-Download. Zum Entfernen des Mods schließen Sie das Spiel und entfernen
Sie winmm.dll, dlssg_sm86.ini und den Ordner dlssg_sm86 neben CursedLands.exe.
Entfernen Sie keine gleichnamigen Dateien aus Windows-Systemordnern.
