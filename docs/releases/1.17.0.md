# Cursed Lands 1.17.0

This release expands autochess recruitment and CPU strategies, improves combat and round transitions, and updates interface text and controls.

- Recruit from **40 creature families**, up from 24, including human fighters and casters, zombies, guards, elementals and other original creatures. Add cross-family evolutions with shared tribes, adjust prices and evolved spells, and bring two final forms’ boss armor into the recruit range.
- Give CPU opponents four spending strategies: **economy, expansion, evolution and tempo**. Rivals save for interest, evaluate army replacements, preserve evolution progress and account for creature spellcasting.
- Run desktop solo autochess combat in a private local worker. Retain terrain between rounds and stage model, animation and shader preparation. Reduce repeated particle, lightning, selection, snow, animation and spectator work during combat, including at **2×** speed.
- Render menu and autochess text at its displayed scale, place **tribe icons beside tribe names**, and use the original cursor in autochess menus. Hold **Q/E** for smooth rotation or drag with the **right mouse button**, independently of battle speed.
- Save a shared **Player name** under **Settings → Remake → Network and co-op**, and reuse it in multiplayer and autochess. New interface and recruit names are translated into English, Russian and German.
- Apply saved character postures before showing loaded or joining characters, including paused solo saves. ([#28](https://github.com/TheWWWorm/CursedLands/issues/28))

Campaign saves, settings, existing solo Trials armies and documented mod interfaces remain supported. Campaign co-op uses protocol **23**; online autochess uses separate protocol **1**. Multiplayer requires matching **1.17.0** builds and compatible original game data. Browser clients require a reachable secure **wss://** endpoint and cannot host. Online play has no late joining, reconnection, host migration or online save/resume. See the [online autochess guide](../autochess-online.md).

Original game data is required and is not included.
