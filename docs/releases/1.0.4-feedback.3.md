# Cursed Lands 1.0.4 Feedback 3

Includes all changes from Feedback 2, including 5% assembly and disassembly fees
for equipment and spells, rune-inclusive prices, and co-op delivery improvements.

- Ordinary creature previews retain their authored scale and position from
  Experimental 2. Oversized creatures retain the bounded preview framing.
- Long character names shrink to fit the unit panel. Short names retain the
  standard font size.
- Graphics presets and automatic detection retain Mirror whenever water
  reflections are enabled. Lower quality tiers can still disable reflections.
  An explicitly chosen Natural mode remains available under Custom settings.
- Settings and campaign buttons tile the original stone texture at its source
  scale instead of stretching it across the button.
- Scripted mechanism locks synchronize to playing clients during play, reload
  and late join. Gate and cage selection follows the visible model parts,
  including their current opening pose. [Issue #2](https://github.com/TheWWWorm/CursedLands/issues/2).
- Campaign state is compressed before reliable transmission. Its periodic
  updates retain the same network cadence at normal and double game speed.
  Slow peers receive the latest pending periodic state after acknowledging the
  previous document. Explicit action results preserve their state ordering.
- Movement snapshot chunks use lossless compression while retaining their
  actor data, packet boundaries, update frequencies and ordering checks.
- Movement outside combat avoids repeated shared-visibility calculations
  when no living actor has an attack or hostile spell order. Audio catch-up
  ticks sample combat visibility once for the unchanged world frame.
- Small ENet commands retry independently of reliable packet backoff. Ordered
  per-player sequences discard duplicate copies, including transaction input,
  while retaining reliable delivery for every command.
- Reused sound channels change their speech/SFX destination under the audio
  lock, preventing concurrent routing changes during native mixing.
- Waterfall spray builds after terrain attachment, using valid world
  transforms and the restored water levels during save loading.

Network protocol is now 20; co-op peers must use the same updated version.
Mod API 1 and earlier campaign saves remain supported. Linux and Windows
packages contain no original game data or saves.
