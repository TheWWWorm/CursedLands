# Cursed Lands 1.5.1-preview.3

Cloud rendering preview based on stable 1.5.0. Includes all changes in
1.5.1-preview.2, including movement and traversal fixes,
and the following changes:

- Keep water's normal-incidence reflection visible from steep camera angles while retaining the swamp colour treatment.
- Bind immutable cloud noise textures when they are created instead of scheduling material texture updates every frame.
- Give the cloud reflection view an independent sky and minimize its unused radiance-cubemap work without changing visible cloud samples or resolution.
- Bind the rain-puddle depression texture independently of terrain detail, so puddles form separate patches with either terrain setting.
- Bound particle-update worker groups to the number of emitters and at most four tasks, avoiding full-pool synchronization for small effects.

This is a backward-compatible patch preview under the [versioning policy](../versioning.md).
Existing campaign saves, network characters, settings, Mod API 1 and texture
Package API 2 remain supported. Co-op uses **network protocol 23**; all players
must use the same build. Graphics presets, cloud ray samples and the visible
cloud-reflection resolution are unchanged.

Downloads cover Windows and Linux x86-64 and the browser export. The hosted
browser build uses the same source. Rendering and performance checks were run
on Linux; Windows/D3D12 and laptop-GPU performance have not been measured.
See the [cloud investigation](../validation/clouds-2026-10-15.md),
[test record](../validation/clouds-2026-10-15.json) and
[release validation](../validation/preview-1.5.1-preview.3-2026-10-15.json).
Bring your own original game data.
