# Cursed Lands 1.9.0

Stable release following 1.8.0.

- Add **Trials of the Allods**, a solo PvE expedition across 30 encounters on a snowy battlefield. Buy a company from original Gipath, Ingos and Suslanger creatures, arrange the formation, and let both teams fight under AI control.
- Add automatic creature evolution, overlapping Beast, Horde, Warrior, Hunter and Mage alliances, level-based recruitment, paid training, interest, win streaks and camp rewards. Each preparation lasts up to 45 seconds; ordinary results advance automatically.
- Add native run-in and repositioning animations, visible snow trails and blood, numeric health, damage feedback, creature details and a HUD that scales through 4K. Keep the opening, menus and feedback localized in English, Russian and German.
- Expand both encyclopedias with 92 character biographies, seven allod articles, revised location histories and original scenery illustrations. Link the accounts to dialogue, journals, event scripts and related characters and places.
- Reduce repeated terrain sampling and colour-cache work. On Android Vulkan, skip unused baked-light, sky-radiance, clear-fog, water-reflection and screen-mipmap work while preserving the selected graphics settings.
- Keep battlefield blood and footprints visible on Mobile and Compatibility renderers by compositing the original marks onto the snow.
- Correct terrain contact on authored bridge decks and use consistent sectors in radial menus.
- Add the YouTube trailer, five new README screenshots and the reusable native 4K60 capture/editing project.

This is a backward-compatible minor release under the [versioning policy](../versioning.md).
Existing campaign saves, network characters, settings, Mod API 1 and texture
Package API 2 remain supported. Earlier local Trials saves migrate their armies
and paid capacity; retired shop and pact investments become company experience.
Co-op uses **network protocol 23** and requires the same build on every participant.
Trials is a solo mode and does not change the campaign's creature database.

Downloads cover Windows and Linux x86-64, Android ARM64, macOS universal and the
browser export. The [hosted game](https://cursedlands.wwworm.com/) and
[public wiki](https://cursedlands.wwworm.com/wiki/) use this release source.
Playing requires original game files; the public wiki does not.

Android retains the application ID and production signing certificate, with
versionCode 41, and includes the qualified Mobile renderer patches. Performance
results vary by scene and graphics settings; detailed paired Retroid Pocket 5
measurements are in the [Android report](../android-vulkan-water-performance-2026-10-17.md).
Windows and macOS packages are audited without native OS runtime testing; macOS
is unsigned. Browser validation covers startup, cached upgrades and encyclopedia
workflows rather than a complete campaign. Trials balance measurements cover
Standard difficulty and deterministic purchasing policies, not human win rates.

See the [release validation](../validation/release-1.9.0-2026-10-17.json) for
combined-build checks, artifact provenance and platform limits.
