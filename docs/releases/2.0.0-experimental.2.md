# Cursed Lands 2.0.0-experimental.2

The experimental Unreal Engine edition is available for Windows x86-64. It uses the original game data from an existing Evil Islands or Lost in Astral installation.

- Improved campaign saves, Quick Load, co-op checkpoint recovery, defeat handling, assisted revival, and travel by a fallen host.
- Corrected co-op experience sharing and dialogue rewards. Eligible tamed pets share solo quest experience.
- Improved quest and spell state restoration, scripted movement, and dialogue staging in the campaign.
- Fixed settings navigation, mouse confinement, path-tracing controls, and camera input. Active quests appear pink on the travel map, and path markers follow raised walkable surfaces.
- Improved path-traced foliage and swamp water. Automatic character lighting turns off while path tracing is active.
- Fixed Direct3D shader issues, kept DLSS optional, and corrected frame-generation swap-chain selection when FSR frame generation is off.

The single Windows build offers DLSS on supported NVIDIA GPUs and Unreal rendering and AMD FSR where supported. Unreal multiplayer uses protocol 1005. All peers need this experimental version. The Godot browser edition has its own version.
