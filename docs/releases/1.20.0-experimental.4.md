# Cursed Lands 1.20.0-experimental.4

Windows AMD FSR preview based on stable 1.19.0.

- Add separate FSR 3.1 and FSR 4 upscaling and 2× frame-generation options.
- Add Native AA, Quality, Balanced and Performance modes with device checks
  and English, Russian and German labels, choices and help.
- Restrict frame generation to active campaign gameplay and suspend it during
  menus, loading and loss of window focus.
- Display the official AMD FSR marks below the Cursed Lands title and in the
  localized credits. Include the SDK and DirectX runtime license notices.

Run `Play-FSR.cmd`, then open Options → Screen → AMD FSR experiment.
Upscaling and frame generation start Off. Unsupported versions are skipped;
selecting FSR 4 never silently selects the 3.1 provider.
Settings and saves use `%APPDATA%\Cursed Lands FSR Experiment`.
Co-op protocol remains 23; use matching preview builds for co-op tests.

See [setup and limitations](../integrations/fsr-experiment.md) and
[validation](../validation/fsr-only.md).
