# Cursed Lands 1.30.0

This release adds save renaming and an optional SHaRC radiance cache, improves cave walls and traversal performance, and repairs campaign timing, load stability and menu presentation.

- Rename manual saves with F2 in the Load and Save screens. Enter applies the name and Esc cancels; the saved world, preview and date are preserved. ([#114](https://github.com/TheWWWorm/CursedLands/issues/114))
- Preserve queued posture changes through killing melee impacts and restore combat readiness when a surviving enemy selects retaliation during its hit animation. ([#113](https://github.com/TheWWWorm/CursedLands/issues/113), [#115](https://github.com/TheWWWorm/CursedLands/issues/115))
- Apply every explicit single-player speed selection to the simulation authority, including after loading a save with a different clock. ([#116](https://github.com/TheWWWorm/CursedLands/issues/116))
- Add an optional SHaRC radiance cache to experimental path tracing, with EN/RU/DE settings and fallback to ordinary path tracing. Reduce repeated scene updates and improve moving sunlight shadows, direct highlights and dense-city scene handling.
- Give natural cave walls consistent world-space texture projection, relief and bounded contours. Raster rendering, path tracing and SHaRC share the visual geometry; original collision and navigation heights remain unchanged.
- Reduce campaign and traversal CPU work through native quest-expression evaluation, actor and mechanism picking, direct-control animation sampling, particle updates, terrain queries, vegetation contacts, foot contacts and ground-mark projection. Script fallbacks remain available.
- Prepare destination cloud resources, contact shaders and the first mirror-water view during loading. Preserve reflections during incremental geometry replacement and avoid redundant ground-mark opacity uploads.
- Handle unindexed weather-cover scenery during Lost in Astral loads and preserve the solo simulation connection through blocking shader compilation. Arm renderer recovery before intro movies.
- Restore original menu caption artwork, align menu boards across window sizes and restore Lost in Astral menu patrols. Correct crash-report hover and keyboard activation.

Windows, Linux, macOS, Android and browser builds require legally obtained original game data. Existing saves and settings remain compatible. Campaign co-op uses protocol 23; Autochess uses protocol 4. Use matching 1.30.0 builds and campaign data for multiplayer.

Path tracing and frame generation remain experimental. Platform test coverage and limitations are recorded separately in the [release validation](https://github.com/TheWWWorm/CursedLands/blob/v1.30.0/docs/validation/release-1.30.0-2026-10-26.json).
