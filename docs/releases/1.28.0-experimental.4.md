# 1.28.0-experimental.4 — Ampere DLSS-G experiment

Local preview based on stable 1.27.0, retaining the DLSS, NRD, path-tracing
and traversal fixes from experimental.3.

- Adds an optional, separately prepared dlssg_for_sm86 0.4.0 package for native
  NVIDIA DLSS-G on Ampere, using one generated frame and the exact consistency
  tier. The normal package keeps its standard NVIDIA SDK capability checks.
- Emits Reflex present markers only when a swap chain is actually presented,
  and samples DLSS-G presentation telemetry once per present.
- Describes frame-generation availability using actual GPU/driver capability
  in English, Russian and German.
- Includes the optional mod's original license and complete third-party
  notices alongside the existing NVIDIA, AMD and NRD attribution.

This is an unpublished local experiment. Native Windows, other RTX 30 models,
HDR, XR and multi-window output remain unqualified. Existing NVIDIA placement
review remains pending. See [setup](../integrations/dlssg-sm86.md) and
[validation](../validation/dlssg-sm86-2026-10-24.md).
