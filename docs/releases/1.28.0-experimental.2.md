# Cursed Lands 1.28.0-experimental.2

Local, unpublished desktop preview. Based on stable 1.27.0; no published tag or
artifact is replaced. Co-op protocol remains 23; use matching builds together.
No save, settings or mod-format migration is introduced.

## English

- Blood marks reuse their ground geometry while growing and rotating, reducing
  CPU work after combat. Their placement, fading and lifetime are preserved.

- Responsive path tracing now uses NVIDIA NRD REBLUR to reduce lighting noise.
  Direct highlights remain sharp. Still scene keeps progressive accumulation;
  unsupported or failed NRD initialization uses the existing filter.
- Nearby scene refreshes reuse mesh, texture and terrain data to reduce stalls
  while travelling.
- Grass and ground cover receive traced light and shadows from their roots.
- Settings are directly under **Remake → Ray tracing / Path tracing**.
- Rainy daylight is dimmer, with improved reconstruction of terrain relief.

Extract the entire preview into a separate folder and run CursedLands.exe on
Windows or Play.sh on Linux. Keep the included `src` folder beside the program.
Select your existing original game-data folder when asked. For NRD, enable
Path tracing and choose Responsive accumulation in the new submenu. Windows
uses DX12; Linux requires Vulkan Forward+ and a ray-tracing GPU.

## Русский

- Пятна крови повторно используют геометрию поверхности при росте и вращении,
  снижая нагрузку на процессор после боя. Положение, затухание и срок жизни
  пятен сохранены.

- Трассировка путей в режиме «Быстрый отклик» использует NVIDIA NRD REBLUR
  для уменьшения шума освещения. Прямые блики остаются чёткими. Режим
  неподвижной сцены сохраняет накопление; если NRD недоступен или не запускается,
  используется прежний фильтр.
- Обновление ближайшей сцены повторно использует данные моделей, текстур и
  ландшафта, уменьшая задержки при перемещении.
- Трава и наземная растительность получают трассированное освещение и тени у
  основания стеблей.
- Настройки доступны прямо в разделе **Ремейк → Трассировка лучей / путей**.
- Дневное освещение во время дождя стало темнее; улучшено восстановление
  освещения рельефа.

Распакуйте весь архив в отдельную папку и запустите CursedLands.exe в Windows
или Play.sh в Linux. Папка `src` должна оставаться рядом с программой. При
запросе выберите существующую папку данных оригинальной игры. Для NRD включите
трассировку путей и режим накопления «Быстрый отклик» в новом разделе настроек.
В Windows используется DX12; в Linux нужны Vulkan Forward+ и видеокарта с
поддержкой трассировки лучей. Для совместной игры используйте одинаковые сборки.

## Deutsch

- Blutflecken verwenden ihre Bodengeometrie beim Wachsen und Drehen erneut.
  Das verringert die CPU-Last nach Kämpfen. Platzierung, Verblassen und
  Lebensdauer bleiben erhalten.

- Reaktionsschnelles Pathtracing verwendet NVIDIA NRD REBLUR, um Bildrauschen
  zu reduzieren. Direkte Glanzlichter bleiben scharf. Die statische Szene behält
  die fortschreitende Akkumulation; bei fehlendem NRD oder einem Startfehler
  wird der bisherige Filter verwendet.
- Beim Aktualisieren der nahen Szene werden Modell-, Textur- und Geländedaten
  wiederverwendet, um Verzögerungen beim Bewegen zu verringern.
- Gras und Bodenbewuchs erhalten berechnetes Licht und Schatten an den Wurzeln.
- Die Einstellungen liegen direkt unter **Remake → Raytracing / Pathtracing**.
- Tageslicht bei Regen ist dunkler; die Beleuchtung des Geländeprofils wird
  genauer rekonstruiert.

Das gesamte Archiv in einen eigenen Ordner entpacken und unter Windows
CursedLands.exe oder unter Linux Play.sh starten. Den mitgelieferten Ordner
`src` neben dem Programm belassen. Bei der Abfrage den vorhandenen Datenordner
des Originalspiels wählen. Für NRD Pathtracing und reaktionsschnelle Akkumulation
im neuen Untermenü aktivieren. Windows verwendet DX12; Linux benötigt Vulkan
Forward+ und eine Grafikkarte mit Raytracing-Unterstützung. Im Koop-Modus
übereinstimmende Builds verwenden.
