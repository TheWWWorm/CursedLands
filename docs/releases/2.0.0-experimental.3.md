# Cursed Lands 2.0.0-experimental.3

The experimental Unreal Engine edition is available for Windows x86-64. It uses the original game data from an existing Evil Islands or Lost in Astral installation.

- Rebuilt the options menu around the edition's own pages: related settings share a row, settings without an effect are gone, and stored values are kept.
- A base shows everyone on it: the unit fog is off in a village ([#170](https://github.com/TheWWWorm/CursedLands/issues/170)). The fog option now also takes effect when it is changed during play.
- Enemies are red on the minimap before they attack ([#179](https://github.com/TheWWWorm/CursedLands/issues/179)).
- In a pause, the mouse wheel zooms ([#177](https://github.com/TheWWWorm/CursedLands/issues/177)) and an order's marks fade as they do in play ([#185](https://github.com/TheWWWorm/CursedLands/issues/185)).
- A conversation on a base no longer resets the game speed chosen for the field ([#130](https://github.com/TheWWWorm/CursedLands/issues/130)).
- The item constructor draws the materials a chosen blueprint cannot use in red ([#125](https://github.com/TheWWWorm/CursedLands/issues/125)).
- A hired mercenary arrives with their own equipment, and keeps what they carried when hired again ([#198](https://github.com/TheWWWorm/CursedLands/issues/198)).
- A zone exit that the map data marks only with an arrival area is shown and usable ([#180](https://github.com/TheWWWorm/CursedLands/issues/180)).
- Items show in every inventory, kit and wheel cell ([#159](https://github.com/TheWWWorm/CursedLands/issues/159)), and screens of a finished level no longer stay over the next one ([#174](https://github.com/TheWWWorm/CursedLands/issues/174)).
- Installed mod packages change the maps and textures they replace ([#152](https://github.com/TheWWWorm/CursedLands/issues/152)).
- Hosting or joining multiplayer under changed rules is refused with an explanation ([#164](https://github.com/TheWWWorm/CursedLands/issues/164)). Save and Load entries that are unavailable in the Esc menu are shown locked ([#142](https://github.com/TheWWWorm/CursedLands/issues/142)).
- Trees carry the edition's own leaves, and steep snow and ice walls, terrain lighting and tree crowns are corrected under path tracing.
- Lost in Astral: campaign units start their patrols at once, a looted body no longer counts as present for scripts, and a quest's experience includes a unit under script control.
- The DLSS plugin's on-screen debug messages are off ([#149](https://github.com/TheWWWorm/CursedLands/issues/149)).

The single Windows build offers DLSS on supported NVIDIA GPUs and Unreal rendering and AMD FSR where supported. Unreal multiplayer uses protocol 1006. All peers need this experimental version. The Godot browser edition has its own version.
