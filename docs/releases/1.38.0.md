# Cursed Lands 1.38.0

This release restores Lost in Astral's Multiplayer board, makes Autochess the default Trials mode and removes a large frame-rate drop on maps with rising water.

- Lost in Astral's main menu has a Multiplayer board in the middle of the signpost again, where the original had one, instead of a bare skull. Its caption is localized and stays sharp at high resolutions.
- Trials of the Allods opens on Autochess by default. Profiles that still had the old Expedition default switch once; a mode you choose afterwards is kept.
- Online Autochess no longer waits out the preparation timer once only computer players are left.
- Fix very low frame rates while a scripted water level rises or falls, such as the river in Lost in Astral's Canyon of Death, for both co-op host and guest (median 15 → 72 fps on the reported save).
- A co-op guest whose story matches the host's keeps full checkpoint credit when the session's first zone loads, and loose ground cover is prepared during loading again so it no longer stutters on first sight.

Windows, Linux, macOS, Android and browser builds require legally obtained original game data. Existing saves and settings remain compatible. Campaign co-op uses protocol 23; Autochess uses protocol 5. Use matching 1.38.0 builds and campaign data for multiplayer.

Path tracing and frame generation remain experimental. The release includes the standard approved graphics runtimes. Platform coverage and limitations are recorded in the [release validation](https://github.com/TheWWWorm/CursedLands/blob/v1.38.0/docs/validation/release-1.38.0-2026-10-30.json); the [changelog](../../CHANGELOG.md) contains the detailed changes.
