# Cursed Lands 1.34.0

This release adds optional ground relief maps, improves path-traced lighting and travel, and updates Autochess and Lost in Astral.

- Add Ground relief maps, an optional terrain setting that is off by default. Load placed map lights, accept PNG texture overrides, retain high-resolution armour layers, and restore the Gipath ogres' skull-belt models.
- Smooth path-traced terrain sunlight and wall shadows, improve lighting coverage and Ray Reconstruction detail during camera travel, and reduce path-tracing CPU work.
- Start the campaign simulation worker during movies and menus to shorten the first new-game or save load of a session.
- Keep the Lost in Astral Wormfaces' Riddle levers usable when the final fortune-teller prediction is bought before the first cave visit. Repair affected saves on load without reopening answered riddles.
- Correct Autochess creature statistics and armour descriptions, snap slightly invalid placements to the nearest valid position, fix explosive-hare blasts, move creature details to the side, and add Options to the Autochess menu.
- Redesign the game-file selector, make the skill-reset option reachable, add an option for the Esc signpost opening animation, and save multiplayer names when leaving the field or screen.
- Add unused faces and inventory models to the cut-content wiki, including the drawing compass, localize the Lost in Astral stealth example in the public guide, and restore fallback icons for game-mechanics pages.

Windows, Linux, macOS, Android and browser builds require legally obtained original game data. Existing saves and settings remain compatible. Campaign co-op uses protocol 23; Autochess uses protocol 5. Use matching 1.34.0 builds and campaign data for multiplayer.

Path tracing and frame generation remain experimental. Platform test coverage and limitations are recorded separately in the [release validation](https://github.com/TheWWWorm/CursedLands/blob/v1.34.0/docs/validation/release-1.34.0-2026-10-28.json).
