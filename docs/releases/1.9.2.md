# Cursed Lands 1.9.2

Stable patch release following 1.9.0.

- Keep pause-menu opening and board animations at the same real-time speed when gameplay is paused, normal or accelerated, including reopening after an interrupted slide. ([#6](https://github.com/TheWWWorm/CursedLands/issues/6))
- Restore normal stamina recovery for companions standing still with a follow order, retaining movement and combat recovery rules. ([#7](https://github.com/TheWWWorm/CursedLands/issues/7))
- Allow party portraits to select follow targets while preserving the acting party selection, with matching target cursors and invalid-target handling. ([#8](https://github.com/TheWWWorm/CursedLands/issues/8))
- Prevent a typed-array error when resolving world tooltips in direct control.

This is a backward-compatible patch under the [versioning policy](../versioning.md).
Existing campaign saves, network characters, settings, Mod API 1 and texture
Package API 2 remain supported. Co-op uses **network protocol 23** and requires
the same build on every participant.

Downloads cover Windows and Linux x86-64, Android ARM64, macOS universal and the
browser export. The [hosted game](https://cursedlands.wwworm.com/) uses this
release source. Playing requires original game files.

Android retains its application ID and production signing certificate, with
versionCode 43. Windows and macOS packages are audited without native OS runtime
testing; macOS is unsigned. Browser validation covers startup and an upgrade
from the 1.9.0 service-worker cache, including preservation of stored data.

See the [release validation](../validation/release-1.9.2-2026-10-17.json) for
regression checks, artifact provenance and platform limits.
