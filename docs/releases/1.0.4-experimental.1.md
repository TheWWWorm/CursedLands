# Cursed Lands 1.0.4 Experimental 1

This preview adds mod profiles and options, fixes two Android simulation freezes, and improves third-person controls. Downloads cover Linux, Windows, Android ARM64 and macOS. Bring your own Evil Islands or Lost in Astral data. All co-op players must update together: network protocol **14**.

- **Mods and rules:** a shared menu for named profiles, built-in rules, package import and generated mod options. Profiles keep separate saves and original-multiplayer characters. API 1 supports configurable revival, texture/audio replacements and selected balance patches. Shared gameplay packages and settings are checked before joining co-op. See the [player and author guide](../mods.md) and asset-free Quick recovery example.
- **Sandbox profiles:** optional invulnerability, unlimited party mana, healing and gold commands. The authority applies changes, and sandbox progress stays separate from ordinary profiles.
- **Android:** a slow loading screen no longer makes the local simulation exit after two minutes, leaving a frozen world and failed saves. Resuming the Android simulation service no longer leaves its tree permanently paused. Intentional menu pauses remain intact.
- **Third person:** keyboard and gamepad movement now steer directly instead of repeatedly issuing pathfinding destinations. Stops, reversals, analog speed, obstacle sliding and pickup are more predictable. Zak relaxes after attack recovery instead of staying in combat stance indefinitely. Gamepad A can select nearby loot without exact crosshair aiming, and releasing movement no longer cancels a new interaction.

Validation includes Android lifecycle and slow-loading checks on Retroid Pocket 5, injected keyboard/gamepad events, authority collisions and real ENet commands. Full physical-controller and campaign playthroughs are outside this validation. Windows and macOS are cross-built; macOS is unsigned and not notarized. Android uses Compatibility rendering by default.

Mods are experimental. Arbitrary scripts/native code, new campaigns, migrations, discovery and broader authoring features are outside API 1. Original game data, player saves and private validation hooks are excluded from public packages. Stable **1.0.3** remains available.
