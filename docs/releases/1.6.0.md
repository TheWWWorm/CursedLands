# Cursed Lands 1.6.0

Stable release following 1.5.0. Includes the
cloud, reflection, movement and traversal changes from 1.5.1-preview.3.

- Publish the [public wiki](https://cursedlands.wwworm.com/wiki/) with GOG edition data, searchable pages, material and blueprint variants, and illustrations in English, Russian and German. It works without game files or an account.
- Add **Game wiki** to the main menu and Esc menu, with searchable pages generated from the installed game databases for items, materials, blueprints, spells, runes and creatures.
- Keep each item on one page, with material/version buttons that update its statistics and live model. Rotate and zoom item and creature models, and calculate spell variants with compatible runes.
- Explain combat, armor, magic, crafting and character formulas using the loaded game data. Provide the interface and explanations in English, Russian and German.
- Vary rain puddle size and spacing with a broader depression field, retaining sparse coverage and receding edges. Keep their muted sheen visible from isometric views in Forward+ and Compatibility.
- Refresh carried weight when adding, removing or consuming belt items, including wands. Deliver guest belt changes and their weight together while paused.

This is a backward-compatible minor release under the [versioning policy](../versioning.md).
Existing campaign saves, network characters, settings, Mod API 1 and texture
Package API 2 remain supported. Co-op uses **network protocol 23**; all players
must use the same build. Cloud quality settings and reflection resolution are unchanged.

Downloads cover Windows and Linux x86-64, Android ARM64, macOS universal and the browser export. The hosted
browser build uses the same source. Read the [wiki guide](../wiki.md) for controls
and data sources. Playing the game requires your own original game data; the public wiki does not.

Rendered checks were run on Linux; Windows/D3D12 and laptop-GPU performance
have not been measured. macOS and Android packages are audited; this release has no new on-device gameplay measurement. See the [combined validation](../validation/wiki-puddles-2026-10-15.json),
[puddle appearance checks](../validation/puddles-2026-10-15.md), and
[release validation](../validation/release-1.6.0-2026-10-15.json).
The earlier performance measurements remain in the
[preview.3 investigation](../validation/clouds-2026-10-15.md).
