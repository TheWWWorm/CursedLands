# Cursed Lands 1.0.4 Experimental 4

This preview combines all changes from [Experimental 3](1.0.4-experimental.3.md), including the Android lifecycle and slow-loading fixes from earlier previews, with the following additions:

- First-person camera mode with a visible body and an eye position that follows the animated model. Character lighting has Auto, Off and On choices; Auto uses it with classic controls.
- Direct attacks can buffer one swing during recovery. Losing control cancels an unstarted swing while preserving a committed impact. Holding pickup no longer restarts the same loot action. Direct keyboard and gamepad movement can walk through open village exits.
- Game setup combines difficulty and optional rules. New campaigns start with a fresh draft of standard settings. Options and mod dialogs use consistent scalable layouts, with scrolling on narrow screens.
- Very low, Very high and Ultra graphics presets, with explicit quality settings independent of automatic detection. Ultra enables the full effect set; unsupported effects take effect after switching to a compatible renderer.
- Optional **Free running outside combat** removes running stamina drain outside combat. It defaults to Off, including in older saves, and retains injuries, carrying limits and spell costs.
- Health bars follow animated head positions, smooth health changes and fade between visibility states. The controlled character's overhead bar is hidden in first person.
- Loading screens remain opaque until the world is ready, including when artwork is unavailable. The HUD stays hidden during initial loading.
- A Python legacy mod converter translates supported texture/audio replacements and existing-record numeric database edits into API 1 packages. Unsupported plugins, scripts, maps and other content produce a report and block packaging. See the [converter guide](../legacy-mod-converter.md) and [compatibility results](../legacy-mod-compatibility.md).

Linux, Windows, Android ARM64 and macOS packages include the combined game changes. The **tools.zip** download contains the converter, package builder, guides, tests and asset-free example. Bring your own Evil Islands or Lost in Astral data. No original game or third-party mod assets are included.

All co-op players need network protocol **16**, which adds direct attack cancellation and the shared free-running rule. Mod API **1** is unchanged. Save-state persistence, stable pet/actor references, co-op return fixes, combat-aware health visibility and Forward+ Mirror geometry reflections remain included.

Technical qualification is recorded separately in the [validation record](../validation/experimental-1.0.4-4-2026-10-11.json). Windows and macOS are cross-built; macOS is unsigned and not notarized. Android defaults to Compatibility rendering. Full campaign-route and multi-machine acceptance remain open. The converter does not make the six inspected complete legacy mods playable.

Stable **1.0.3** remains available.
