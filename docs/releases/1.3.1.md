# Cursed Lands 1.3.1

- Keep Mirror water reflections aligned with the main camera during rapid movement, removing temporary gaps along reflected shores.
- Correct fog colours in distant Mirror reflections, removing red daylight and green nighttime patches. This applies with both original textures and HD Lands.

This is a patch release under the [versioning policy](../versioning.md).
Existing campaign saves, network characters, settings, mod profiles, Mod API 1
and texture Package API 2 remain supported. Co-op uses **network protocol 23**.
All players should use 1.3.1; mixed-version sessions are unsupported.

Downloads cover Linux x86-64, Windows x86-64, macOS universal, Android ARM64,
the browser export and the mod-tools bundle. The hosted browser build uses the
same source. Mirror scene reflections use Forward+; other renderers retain
their existing water paths. Bring your own original game data.

Validation and platform limits are recorded separately in the
[release validation record](../validation/stable-1.3.1-2026-10-14.json).
