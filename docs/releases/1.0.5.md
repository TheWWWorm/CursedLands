# Cursed Lands 1.0.5

- Update the optional HD Lands texture package to **1.5.0**, with 390 textures
  selected from the original resource configuration.
- Prefer the archive hosted on **Gipat** and use **Yandex Disk as backup** when
  the primary download fails. Both sources use the same pinned size and SHA-256.
- Keep cancellation responsive when a download server stops responding.
- Keep rune icons inside the upper-left border of shop and spell-constructor
  cells, with space for stack quantities and prices.

This is a patch release under the [versioning policy](../versioning.md).
Existing saves, settings, mod profiles, Mod API 1 and texture Package API 2 remain
supported. Installed HD Lands 1.4.0 packages are retained; install and enable
1.5.0 in a named profile to use it. Co-op uses **network protocol 21**; use the
same build for all peers.

Downloads cover Linux x86-64, Windows x86-64, macOS universal and Android ARM64,
plus the mod-tools bundle. The optional HD Lands download remains available for
the base campaign on Windows and Linux. Bring your own original game data;
original game files, player saves and third-party mod assets are not bundled.

Validation and platform limits are recorded separately in the
[release validation record](../validation/stable-1.0.5-2026-10-13.json).
