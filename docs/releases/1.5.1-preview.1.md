# Cursed Lands 1.5.1-preview.1

Local performance preview based on stable 1.5.0.

- Retain grass instance data on the CPU before bulk upload, avoiding GPU readbacks when camera movement changes grass detail.
- Reuse authored water geometry for mist, ambient life and water-contact queries as the camera enters new sectors.
- Reuse retained scenery triangles for camera occlusion tests before fading objects in front of the party.
- Reuse regional particle habitat results for overlapping camera cells, with bounded storage and invalidation when scenery or water levels change.
- Prepare regional wildlife shaders during map loading, including tinted snow mice and frogs that first appear away from the starting view.

Graphics presets, reflection resolution, shadow quality and vegetation density
remain unchanged. No settings or player-facing text are added.

This previews a backward-compatible patch under the [versioning policy](../versioning.md).
Existing campaign saves, network characters, settings, Mod API 1 and texture
Package API 2 remain supported. Co-op uses **network protocol 23**; players
should use the same build, since mixed-version sessions are unsupported.

The local packages target Windows and Linux x86-64. Performance measurements
and renderer tests were run on Linux; Windows/D3D12 performance has not been
measured. No public release or hosted browser update is included.
See the [validation record](../validation/map-pan-2026-10-15.json) for evidence
and remaining limits. Bring your own original game data.
