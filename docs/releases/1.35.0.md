# Cursed Lands 1.35.0

This release extends texture modding, keeps the Windows Direct3D 12 menu responsive after an update, and fixes several original-game bugs.

- Let texture packs replace the main-menu and Esc-menu signpost textures in `menus.res`. The new `tools/export_textures.py` exports the original MMP textures as lossless full-colour PNGs in the texture-pack folder layout, so they can be edited and repackaged without MMP or DXT tools.
- Keep the Windows Direct3D 12 main menu drawing when DLSS, TAA or FSR 2 needs new motion-vector shaders, for example after an update. The selected mode starts once its shaders are ready in the background; previously the first frame could stall for tens of seconds or never finish.
- Fix original-game bugs that the Rebirth edition also fixes: Destruction and Astral Rift quick casts aim at enemies instead of the caster, a negative Use value no longer opens skill-locked levers, Antimagic no longer starts battle music, timed effects keep counting down on distant sleeping units, and the disassembly fee includes the repair cost of wear.
- Show Lost in Astral's own loading movies on Gipat2 and Jigran, and order the AI's list of nearby units as the original refresh does.
- Keep Autochess live-board tournament saves loadable after round 30.

Windows, Linux, macOS, Android and browser builds require legally obtained original game data. Existing saves and settings remain compatible. Campaign co-op uses protocol 23; Autochess uses protocol 5. Use matching 1.35.0 builds and campaign data for multiplayer.

Path tracing and frame generation remain experimental. Platform test coverage and limitations are recorded separately in the [release validation](https://github.com/TheWWWorm/CursedLands/blob/v1.35.0/docs/validation/release-1.35.0-2026-10-28.json).
