# Cursed Lands 1.21.0

- Add a developer console with syntax colours, matching brackets, command and argument completion, searchable help and output, persistent history, adjustable text size, clipboard copying and local diagnostic exports. Add host testing commands for party inspection, healing, basic GodMode, teleporting, direct map travel and scene time. Retain supported original script expressions and authenticated host execution. Help and controls are available in English, Russian and German. ([#65](https://github.com/TheWWWorm/CursedLands/issues/65))
- Support `redress.res` texture overrides in API 1/2/3 mod packages and the legacy converter, covering character skins, clothing and equipment. ([#66](https://github.com/TheWWWorm/CursedLands/issues/66))
- Prepare Windows FSR resources asynchronously, expose frame generation independently of upscaling, and distinguish presented from rendered frame rates. Keep capability guidance in Screen settings.
- Share foliage height materials to reduce shader parameter-buffer exhaustion.
- Preserve attackers after ranged hits, restore context-sensitive self-casting and Alt target selection, retain curse placement and presentation, and handle ending audio transitions. ([#48](https://github.com/TheWWWorm/CursedLands/issues/48))
- Correct LiA merchant purchases and party ownership, stage co-op dialogue actors consistently, recover the eavesdrop objective when speakers die, and complete the paid-rumour torch handoff through the original mechanism script. ([#47](https://github.com/TheWWWorm/CursedLands/issues/47))
- Align objective-chain completion, mechanism permission consumption, movement rounding, future-position queries, scene/campaign clocks and town-save continuation with the supported original behavior. Preserve Enlarge/Shrink duration and notify nearby allies about non-damaging hostile spells. ([#62](https://github.com/TheWWWorm/CursedLands/issues/62), [#64](https://github.com/TheWWWorm/CursedLands/issues/64))
- Add LiA challenge rewards, use finished-item names in the wiki, and allow held right-click to reduce camp stats and skills.

Open the console with the physical grave/tilde key, then click **Enable commands**. Start with `help`, `party`, `inspect selected` or `report bug.txt`. See the [console guide](../console.md), [mod guide](../mods.md) and [validation record](../validation/release-1.21.0-2026-10-21.json).

Existing campaign saves, characters, profiles and API 1/2/3 mod packages remain supported. Campaign co-op uses protocol **23**, Autochess uses protocol **1**, and peers must use the same game version with matching gameplay mods. Basic GodMode supports modes 0 and 1; mode 2 remains unsupported. Windows FSR requires Direct3D 12 and supported hardware/runtime versions. The macOS package is unsigned.

## Русский

В версии 1.21.0 добавлена удобная консоль для тестирования: подсветка синтаксиса, парные скобки, дополнение команд и аргументов, поиск в справке и выводе, сохранение истории, настройка шрифта и локальные отчёты. Команды позволяют осматривать и лечить отряд, включать обычную неуязвимость, перемещать персонажей, переходить между картами и управлять временем сцены. Откройте консоль клавишей под Esc, нажмите **Включить команды** и введите `help`. Изменять кампанию может только сервер.

Также добавлена поддержка текстур `redress.res` в модах и конвертере. Подготовка FSR в Windows выполняется асинхронно; генерация кадров настраивается независимо от масштабирования. Обновлены поведение боевых целей, задания и торговля LiA, механизмы, движение, часы кампании и сцены, загрузка городских сохранений, длительность изменения размера, награды испытаний и названия готовых предметов в вики.

Сохранения, профили и моды API 1/2/3 совместимы. Протокол кампании — **23**, Autochess — **1**; участникам нужны одинаковая версия игры и набор игровых модов. Режим GodMode 2 не поддерживается. Пакет macOS не подписан.

## Deutsch

Version 1.21.0 ergänzt eine Testkonsole mit Syntaxfarben, Klammerpaaren, Befehls- und Argumentergänzung, durchsuchbarer Hilfe und Ausgabe, gespeichertem Verlauf, einstellbarer Schrift und lokalen Diagnoseberichten. Befehle untersuchen und heilen die Gruppe, schalten grundlegende Unverwundbarkeit ein, versetzen Einheiten, wechseln Karten und steuern die Szenenzeit. Die Taste unter Esc öffnet die Konsole; anschließend **Befehle aktivieren** und `help` eingeben. Nur der Host darf die Kampagne ändern.

Mods und Konverter unterstützen nun `redress.res`-Texturen. Windows bereitet FSR asynchron vor; Frame-Generierung lässt sich unabhängig vom Upscaling einstellen. Aktualisiert wurden Kampfziele, LiA-Aufgaben und Handel, Mechanismen, Bewegung, Kampagnen- und Szenenzeit, das Laden von Stadtspeicherständen, die Dauer von Größenzaubern, Herausforderungsbelohnungen und fertige Gegenstandsnamen im Wiki.

Spielstände, Profile und Mods mit API 1/2/3 bleiben kompatibel. Die Kampagne verwendet Protokoll **23**, Autochess **1**; Mitspieler benötigen dieselbe Spielversion und dieselben Gameplay-Mods. GodMode 2 wird nicht unterstützt. Das macOS-Paket ist unsigniert.
