# Cursed Lands 1.18.0

This stable release rebuilds Trials around 28 distinct creature species and three ranks of each species, with one shop price per species across all five price tiers. It also adds campaign control options, co-op corrections, Discord activity, and the approved dragon startup branding.

## Trials

- Rebalance health, typed armor, native attack cadence, regeneration and spell damage, including persistent spell lifetime and healing. Revise six alliances and late-level progression.
- Use a closer default camera, brighter clearing, compact creature details, tier-colored stars, clearer upgrade signals and brief round notices above the fight.
- Mark the planning boundary with a low fire effect. Surviving creatures send fire bolts toward the losing player's name; health loss applies immediately.
- Preserve bench positions and swap occupied field/bench slots. Repair scouting visibility, watched-player damage lists, spectator inspection, sale quotes, upgrade notifications and LAN lobby discovery.

## Campaign and co-op

- Queue confirmed spells ahead of repeated weapon attacks, allow interactions to cancel spell aiming, and run toward double-clicked interactions.
- Right-click a skill or ability's price button in camp to refund one rank. Add experience-sharing options and optional control hints; default enemy health bars to Always while preserving saved preferences.
- Repair portrait proportions, replicated movement and action timing, creature weapon animations, spell attachment points, help calls and hostility updates.
- Preserve personal progression and shared story checkpoints when co-op participants return. Restore the captive lizard's follow-up conversation and improve quest-list scrolling.
- Correct paused loading, save multi-selection, prone casting, posture replication, aimed approach targets and collected-item feedback. See the [full changelog](../../CHANGELOG.md) for issue links.
- Add Windows/Linux Discord activity with the application ID built in. Players need only the Discord desktop app and the enabled game option; [setup and privacy details](../integrations/discord.md).

## Presentation and startup

- Use the approved transparent dragon CL artwork for application icons, with a smaller logo and Cursed Lands title below it on the splash screen.
- Apply the game window title before the first visible startup frame in the rebuilt Windows and Linux engines.
- Restore wisp crystals and ambient stars; release delayed and refreshed spell-ending effects with their world or carrier.

## Compatibility and downloads

- Existing campaign saves, profiles and documented mod API remain supported. Trials saves migrate to the species roster while retaining investment and placement.
- Campaign co-op protocol is 23; Trials protocol is 1. All participants must use **1.18.0**; do not mix game versions.
- Windows and Linux include rebuilt Godot 4.7 engines with the desktop startup-title patch. macOS uses the official universal template and is unsigned; Android retains its qualified production engine and signing certificate. Original game data is required and is not bundled.
- The longer Windows co-op frame-rate degradation remains under investigation; this release does not claim to resolve it.
