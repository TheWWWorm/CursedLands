# Cursed Lands 1.5.1-preview.4

Puddle visibility preview based on stable 1.5.0. Includes all cloud, reflection,
movement and traversal changes from 1.5.1-preview.3.

- Give small rain puddles a muted sky sheen that remains visible from the isometric camera, retaining their sparse coverage, soft margins and drying behaviour.

This is a backward-compatible patch preview under the [versioning policy](../versioning.md).
Existing campaign saves, network characters, settings, Mod API 1 and texture
Package API 2 remain supported. Co-op uses **network protocol 23**; all players
must use the same build. Cloud quality settings and reflection resolution are unchanged.

Downloads cover Windows and Linux x86-64 and the browser export. The hosted
browser build uses the same source. Rendered checks were run on Linux;
Windows/D3D12 and laptop-GPU performance have not been measured.
See the [puddle visibility checks](../validation/puddles-2026-10-15.md),
[test record](../validation/puddles-2026-10-15.json) and
[release validation](../validation/preview-1.5.1-preview.4-2026-10-15.json).
The earlier performance measurements remain in the
[preview.3 investigation](../validation/clouds-2026-10-15.md).
Bring your own original game data.
