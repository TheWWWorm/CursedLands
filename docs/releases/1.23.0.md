# Cursed Lands 1.23.0

- Add optional experimental ray-traced water reflections on Windows and Linux. Select **Forward+ (Vulkan)** under Screen settings, then **Graphics → Water → Water reflections → Ray traced (test)**. An RT-capable Vulkan GPU and driver are required; the included desktop executables contain the engine patch. Existing defaults and graphics presets remain unchanged.
- Reflect nearby terrain, scenery and animated creatures, including the complete first-person player figure. Preserve cutout foliage and trace hard shadows from the sun and nearby lights. Support material tint, solid-colour HDR emission and live updates to supported material properties.
- Keep Mirror visible while preparing or rebuilding the RT scene. Unsupported hardware and other rendering APIs retain their established fallback. Windows FSR continues to use Direct3D 12; it cannot run together with Vulkan RT.
- Correct sky-coloured wedges on reverse-facing river triangles in the enhanced water modes.

RT remains experimental: it uses a bounded scene and a lower-resolution reflection target, with approximate lighting. Particles, shader-only wind, blended transparency and global illumination are omitted. It does not promise higher overall FPS. See the [water reflection guide](../integrations/water-raytracing-experiment.md).

Existing campaign saves, characters, profiles and API 1/2/3 mod packages remain supported. Campaign co-op uses protocol **23**, Autochess uses protocol **1**, and peers must use the same game version with matching gameplay mods. macOS, Android and browser packages retain their existing reflection paths. The macOS package is unsigned.

## Русский

Версия 1.23.0 добавляет экспериментальную трассировку отражений на воде для Windows и Linux. Выберите **Forward+ (Vulkan)** в настройках экрана, затем **Графика → Вода → Отражения на воде → Трассировка (тест)**. Требуются видеокарта и драйвер Vulkan с поддержкой трассировки лучей; необходимые изменения движка включены в настольные сборки. Настройки по умолчанию и предустановки графики не изменены.

В воде отражаются ландшафт, объекты и движущиеся существа, включая полную фигуру игрока в режиме от первого лица. Сохраняются вырезы листвы, учитываются тени от солнца и ближайших источников света, цвет и свечение материалов. Изменения поддерживаемых свойств материалов обновляют отражение. Во время подготовки используются зеркальные отражения. Исправлены яркие участки неба на обратных гранях речной поверхности.

Трассировка использует ограниченную область сцены и пониженное разрешение; частицы, движение листвы в шейдерах, полупрозрачные поверхности и глобальное освещение не поддерживаются. Прирост общей частоты кадров не гарантируется. FSR в Windows требует Direct3D 12 и не работает одновременно с трассировкой Vulkan. На macOS, Android и в браузере сохраняются прежние способы отражения.

Сохранения, профили и моды API 1/2/3 совместимы. Протокол кампании — **23**, Autochess — **1**; участникам нужны одинаковая версия игры и набор игровых модов. Пакет macOS не подписан.

## Deutsch

Version 1.23.0 ergänzt experimentelle Wasserreflexionen mit Raytracing für Windows und Linux. Wählen Sie **Forward+ (Vulkan)** in den Bildschirmoptionen und anschließend **Grafik → Wasser → Wasserreflexionen → Raytracing (Test)**. Erforderlich sind eine Vulkan-Grafikkarte und ein Treiber mit Raytracing-Unterstützung; die nötige Engine-Anpassung ist in den Desktop-Paketen enthalten. Standardwerte und Grafikvoreinstellungen bleiben unverändert.

Reflektiert werden Gelände, Objekte und bewegte Kreaturen einschließlich der vollständigen Spielfigur in der Ich-Perspektive. Aussparungen im Laub bleiben erhalten; Sonne und nahe Lichtquellen werfen berechnete Schatten. Materialfarbe, Leuchten und Änderungen unterstützter Materialeigenschaften werden berücksichtigt. Während der Vorbereitung bleiben Spiegelreflexionen sichtbar. Himmelsfarbene Keile auf rückseitigen Flussflächen sind korrigiert.

Raytracing verwendet einen begrenzten Szenenbereich und eine geringere Auflösung. Partikel, im Shader bewegtes Laub, halbtransparente Flächen und globale Beleuchtung werden nicht unterstützt. Eine höhere Gesamtbildrate wird nicht zugesichert. Windows-FSR benötigt Direct3D 12 und kann nicht gleichzeitig mit Vulkan-Raytracing laufen. macOS, Android und Browser behalten ihre bisherigen Reflexionsverfahren.

Spielstände, Profile und Mods mit API 1/2/3 bleiben kompatibel. Die Kampagne verwendet Protokoll **23**, Autochess **1**; Mitspieler benötigen dieselbe Spielversion und dieselben Gameplay-Mods. Das macOS-Paket ist unsigniert.
