# Cursed Lands 1.10.0

Stable feature release following 1.9.2.

- Add combat shopping, reserve sales, independent offer locks and three-star
  evolutions for every Trials recruit family. Deployed upgrades appear next round.
- Put company level, XP, prices and recruitment odds in compact shop controls.
  Fit inspectors to their content, center utility icons, and use whole reward
  cards with original item artwork. Keep the HUD and creature animations visible
  after rounds, with notifications and countdowns at the top.
- Pay income after defeats and advance every completed wave. Use the remake’s
  80% armor absorption cap on both sides, a two-minute defeat limit, and revised
  encounter formations, recruit prices and preparation times. Damaging spells
  cannot hit allies in Trials. ([#15](https://github.com/TheWWWorm/CursedLands/issues/15))
- Add a native-styled choice between starting-skill restoration and a full refund
  at camp. ([#5](https://github.com/TheWWWorm/CursedLands/issues/5))
- Show paths during tactical pause, honor explicit attack-move in defensive
  stance, and show the route when acquiring a target.
  ([#12](https://github.com/TheWWWorm/CursedLands/issues/12), [#13](https://github.com/TheWWWorm/CursedLands/issues/13), [#14](https://github.com/TheWWWorm/CursedLands/issues/14))
- Suppress incidental voices during quest dialogue and render the opening
  signpost pose before displaying it.
  ([#10](https://github.com/TheWWWorm/CursedLands/issues/10), [#11](https://github.com/TheWWWorm/CursedLands/issues/11))
- Cache encyclopedia indexes, virtualize search results, space navigation buttons,
  and expand Kel’s biography with the original resurrection requirements and
  fragment guide. All new game and encyclopedia text is in English, Russian and German.
- Put Mods and rules, Encyclopedia and Trials in a bottom menu row. Name the mode
  Trials of the Allods / Испытания аллодов and offer it only for the original campaign.

This is a backward-compatible feature release under the [versioning policy](../versioning.md).
Campaign saves, network characters, settings, Mod API 1 and texture Package API 2
remain supported. Trials schema ten migrates older runs. Campaign armor choices
are preserved. Co-op uses **network protocol 23** and requires the same build on
all participants.

Downloads cover Windows and Linux x86-64, Android ARM64, macOS universal and Web.
The [hosted game and wiki](https://cursedlands.wwworm.com/) use this release source.
Playing requires original game files. Android retains its application ID and
production signing certificate, with versionCode 44. macOS is unsigned.

See the [release validation](../validation/release-1.10.0-2026-10-17.json),
[Trials measurements](../validation/trials-ui-balance.md) and
[Kel guide validation](../validation/kel-wiki-2026-10-17.json) for evidence and
platform limits. Automated balance policies are not human win-rate estimates.
