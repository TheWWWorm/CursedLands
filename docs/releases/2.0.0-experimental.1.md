# Cursed Lands 2.0.0-experimental.1

The experimental Unreal Engine 5.8 edition is available for Windows x86-64.
It uses an existing Evil Islands or Lost in Astral installation for the original game data.

The Windows download contains one game build. Graphics settings offer DLSS on
supported NVIDIA GPUs. With DLSS off, the same executable can use Unreal's
built-in renderer and upscaler or AMD FSR where supported. Real-time path tracing
and hardware-dependent reconstruction and frame generation have separate settings.

- Fixed a crash when opening Autochess and corrected right-button camera drag.
- Moved the first-person quest backdrop capture off the blocking render path.
- Extended path-traced grass shadows around the tactical camera's ground focus.

Unreal co-op uses protocol 1004 and requires matching Unreal builds.
The browser edition continues to use Godot.
