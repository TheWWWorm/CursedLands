# Cursed Lands 1.0.4 Experimental 2

This preview includes the mod menu and support, Android simulation lifecycle changes and third-person controls from [Experimental 1](1.0.4-experimental.1.md), plus a co-op loading fix.

- Saved mod compatibility is checked before starting the loading transition. A refused save leaves the current world, commands, saving, pause state and speed available.
- While a host restores different saved mod values without guests, incoming players receive a retry notice. Players with matching values can join after loading completes.

Download packages are available for Linux, Windows, Android ARM64 and macOS, together with the asset-free Quick recovery example mod. Bring your own Evil Islands or Lost in Astral data. All co-op players need network protocol **14**. Mod API **1** is unchanged; see the [player and author guide](../mods.md).

The [validation record](../validation/experimental-1.0.4-2-2026-10-11.json) documents co-op load rejection and reconnection, repeated spell input, original multiplayer commands and Retroid Pocket 5 checks. Keyboard/gamepad checks use injected events. Windows and macOS are cross-built; macOS is unsigned and not notarized. Android uses Compatibility rendering by default.

Stable **1.0.3** remains available.
