# 1.28.0-experimental.5 — PT travel and presentation

Local preview based on stable 1.27.0, retaining the DLSS, NRD and optional
dlssg_for_sm86 integration from experimental.4. Network protocol 23, formula
API 1 and package API 3 remain unchanged; use matching builds for co-op.

- Warm projected ground-mark materials during loading, reuse ray pipelines
  across region changes and stage replacement acceleration structures.
- Preserve NRD history for compatible surfaces across region replacements.
  Reject changed and deformed surfaces independently.
- Add **PT rendered frame target** under Remake → Ray tracing / Path tracing,
  with Off, 30, 45 and 60 FPS choices. Responsive PT can gradually adjust its
  resolution within a bounded range. Labels, choices and help include EN/RU/DE.
- Apply nearby grass shadow-map occlusion to traced direct sunlight while
  preserving indirect light. The effect fades out between 18 and 24 metres.
- Supply DLSS-G with real HUD opacity and inputs sized to the final output.
  Unsupported cropped mappings retain ordinary rendering with FG suspended.

This is an unpublished local preview. Native Windows frame pacing remains
pending; Proton SDK counters do not qualify Windows pacing. HDR, XR and
multi-window output remain unqualified. Existing NVIDIA placement review
remains pending. SDK files, optional-mod licenses and attribution are retained.

[DLSS setup](../integrations/nvidia-dlss.md), and
[optional Ampere FG setup](../integrations/dlssg-sm86.md).
[Validation and the Windows capture procedure](../validation/pt-five-targets-2026-10-24.md)
record the actual traversal results and remaining limitations.
