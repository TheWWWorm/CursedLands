# Cursed Lands 1.31.1

Restore the complete offline wiki in the standalone browser download, matching the hosted wiki's articles, translations, icons and interface. Add an archive regression that checks every wiki file and its bytes against the committed site.

This patch retains the gameplay and rendering changes from [1.31.0](https://github.com/TheWWWorm/CursedLands/releases/tag/v1.31.0). Windows, Linux, macOS, Android and browser builds require legally obtained original game data. Saves and settings remain compatible. Campaign co-op uses protocol 23; Autochess uses protocol 4. Use matching 1.31.1 builds and campaign data for multiplayer.

Platform checks and inherited runtime coverage are recorded in the [release validation](https://github.com/TheWWWorm/CursedLands/blob/v1.31.1/docs/validation/release-1.31.1-2026-10-26.json).
