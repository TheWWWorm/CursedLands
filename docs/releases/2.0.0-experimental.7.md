# Cursed Lands 2.0.0-experimental.7

The experimental Unreal Engine edition is available for Windows x86-64. It uses the original game data from an existing Evil Islands or Lost in Astral installation.

- Co-op guests share the host’s unit presentation and field control rules. Movement, camera and combat feedback use a common presentation path, including at 2× speed. Network updates follow real time, prioritize nearby activity and skip unchanged views.
- Pickup and inventory updates preserve the guest’s selected hero and on-screen controls. Guest interaction includes shared targeting, contextual hints and exit handling. The host saves acknowledged guest progress before departure, and a returning player can reclaim the existing hero and seat after a connection loss.
- Installed texture packs can be used in co-op with the original gameplay rules. [#220](https://github.com/TheWWWorm/CursedLands/issues/220)
- First-person and third-person village conversations release the cursor for dialogue choices. The Gipat pig briefing targets the authored pig, and unfinished Cave quests remain available in the multiplayer journal. [#212](https://github.com/TheWWWorm/CursedLands/issues/212) [#213](https://github.com/TheWWWorm/CursedLands/issues/213) [#209](https://github.com/TheWWWorm/CursedLands/issues/209)
- Held character-creation controls repeat attribute and skill changes. Character previews keep animating during appearance and equipment edits. [#206](https://github.com/TheWWWorm/CursedLands/issues/206) [#207](https://github.com/TheWWWorm/CursedLands/issues/207)
- Raster village lamps and hero lights stay active while the camera pans. [#208](https://github.com/TheWWWorm/CursedLands/issues/208)
- The item constructor uses the selected material source first. Replacing or cancelling a movement order preserves the intended gait or stop. Crash reporting preserves pending records and attaches logs from the matching session.

Unreal co-op uses protocol **1026**, and online Arena uses protocol **1006**. All Unreal peers need this experimental version. The Godot browser edition has its own version.
