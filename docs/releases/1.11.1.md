# Cursed Lands 1.11.1

- Normalize embedded shader line endings before composition and keep GDScript and shader files at LF in Git checkouts. Shader declarations and initialization now remain consistent in Windows source checkouts.
- Keep graphics preset application running when an earlier terrain update frees nodes from the scene snapshot. Remaining terrains and option listeners still receive the update.
- Document the safe rendering-thread configuration for running from source with official Godot builds.

Campaign saves, settings, existing Trials armies and documented mod interfaces
remain supported. Co-op retains protocol **23** and requires matching game
versions. Original game data is required and is not included.
