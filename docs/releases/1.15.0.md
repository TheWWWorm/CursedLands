# Cursed Lands 1.15.0

Autochess now supports online PvP for up to nine players, with computers filling empty seats and taking over departing guests. Open **Trials of the Allods → Autochess → Play online** to host or join through the familiar campaign co-op connection window. It includes address copy/paste, recent addresses, optional passwords, readiness and a nine-seat roster.

- The host runs the shared preparation timer, purchases, native battles and results. Players have separate shops, gold, armies and health. Scouting and the nine-board overview remain available; eliminated players can keep watching.
- Press **F7** to open the wiki for the item, spell, creature, quest or map under the pointer. With no subject under the pointer, it opens the wiki home page. Rebind **Wiki under pointer** in **Options → Windows**. Standalone wiki buttons have been removed. Online play continues while the wiki is open.
- Set **Options → Sound → Cave echo** to **Off** for dry cave audio. The choice previews immediately and is saved with other audio settings; it defaults to **On**.
- Render extra main-menu button borders at their native texture density. New controls, help, choices and connection messages have English, Russian and German translations.

Online autochess uses separate protocol **1** and requires matching builds and compatible original game data. Native clients use UDP by default or WebSocket when selected. Internet hosting needs a reachable port; browser clients can join a secure **wss://** endpoint but cannot host. The first online version has no late joining, reconnection, host migration or online save/resume. Leaving as host closes the match. See the [online autochess guide](../autochess-online.md).

Campaign saves, settings, existing solo Trials armies and documented mod interfaces remain supported. Campaign co-op retains protocol **23** and requires matching game versions. Original game data is required and is not included.
