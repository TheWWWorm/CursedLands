# Cursed Lands 1.36.0

This release improves path tracing and map loading, expands material coverage, and includes all accepted changes since 1.35.0.

- Give more objects in both campaigns matching stone, plaster, wood, metal, clay, bone and cloth materials. Lost in Astral autumn trees now receive leaf transmission and bark detail.
- Reduce the cost of path tracing, ReSTIR lighting, refraction and denoising. Preserve lighting history around moving lights and remove redundant work in Ray Reconstruction. Fix the NVIDIA Vulkan terrain-pipeline crash and late lighting changes during fast night travel.
- Overlap map parsing, navigation, terrain and animation preparation during loading, and let clients prepare their world while the host builds it. Reduce work for distant actors and empty perception scans.
- Restore original combat and creature decisions: scripted escorts, alarm behaviours, hostility sharing, staged taming, attack noise, damaged body-part targeting, out-of-reach attacks, high flyers, Feeblemind and hit-reaction timing.
- Carry mana correctly between zones. Give the save/load and mod panels proper gamepad focus, with X to delete and Y to rename on the save screen.
- Keep encyclopedia and spell-constructor text readable at 1440p and 4K. Complete Russian and German mod messages and unify interface scaling and confirm/cancel handling.
- Add native Windows development tooling and stronger automated regression, translation and issue-coverage checks. Improve capture-size and traversal fixtures so graphics tests verify their actual output.

Windows, Linux, macOS, Android and browser builds require legally obtained original game data. Existing saves and settings remain compatible. Campaign co-op uses protocol 23; Autochess uses protocol 5. Use matching 1.36.0 builds and campaign data for multiplayer.

Path tracing and frame generation remain experimental. The release includes the standard approved graphics runtimes. Platform coverage and limitations are recorded in the [release validation](https://github.com/TheWWWorm/CursedLands/blob/v1.36.0/docs/validation/release-1.36.0-2026-10-29.json); the [changelog](../../CHANGELOG.md) contains the detailed changes.
