# Cursed Lands 1.36.1

This patch fixes attack orders on creatures the party has not yet noticed.

- Let party members attack a unit the player can see even when no party member has noticed it yet, such as a creature behind the hero. In 1.36.0 the hero acknowledged the order but did not move. The order still ends with "no target" once the player can no longer see the target.

Windows, Linux, macOS, Android and browser builds require legally obtained original game data. Existing saves and settings remain compatible. Campaign co-op uses protocol 23; Autochess uses protocol 5. Use matching 1.36.1 builds and campaign data for multiplayer.

Path tracing and frame generation remain experimental. The [changelog](../../CHANGELOG.md) contains the detailed changes.
