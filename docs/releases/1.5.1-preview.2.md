# Cursed Lands 1.5.1-preview.2

Movement and traversal preview based on stable 1.5.0. Includes the changes in
1.5.1-preview.1 and the following fixes:

- Smooth the local player's movement with continuous path samples and a single update stream, retaining ordinary co-op updates for remote players. ([#4](https://github.com/TheWWWorm/CursedLands/issues/4))
- Reuse far-grass bounds and precompute sorting priorities during camera movement.
- Copy terrain shader values without enumerating renderer properties when creating snow-track sectors.
- Prepare footprint textures and map-specific foot shapes during loading.
- Refresh both actor roots and model transforms when figures reappear after moving out of sight.

This is a backward-compatible patch preview under the [versioning policy](../versioning.md).
Existing campaign saves, network characters, settings, Mod API 1 and texture
Package API 2 remain supported. Co-op uses **network protocol 23**; all players
must use the same build. Graphics presets and quality settings are unchanged.

Downloads cover Windows and Linux x86-64 and the browser export. The hosted
browser build uses the same source. Rendering and performance checks were run
on Linux; Windows/D3D12 and laptop-GPU performance have not been measured.
See the [investigation and test results](../validation/traversal-2026-10-15.json)
and [release validation](../validation/preview-1.5.1-preview.2-2026-10-15.json)
for evidence and remaining reproduction limits. Bring your own original game data.
