# 1.28.0-experimental.3 — DLSS restoration

Local preview based on stable 1.27.0. Includes all NRD, traversal-performance
and ray-tracing menu changes from experimental.2.

- Restores NVIDIA DLSS Super Resolution and DLAA in Screen → Anti-aliasing.
  Native AA selects DLAA. Quality, Balanced and Performance are available.
- Restores the SDK-gated 2× NVIDIA frame-generation path with Reflex.
  RTX 30-series does not support this feature; it remains unavailable there.
- Keeps AMD and NVIDIA presentation ownership exclusive, with an apply/restart
  prompt when switching. Quality changes within DLSS apply live.
- Restores package-aware NVIDIA and AMD artwork/credits and adds the missing
  NRD credits on Windows and Linux. All UI/help/credits use English, Russian
  and German. Complete SDK notices are bundled and checked against pinned hashes.
- Preserves the current DirectX Agility runtime and the path-tracing fixes.
- Keeps DLSS active through forced shader warm-up draws and retains the local
  simulation connection during Windows loads longer than two minutes.

Use the ordinary Windows executable, choose Forward+ (Direct3D 12), then
NVIDIA DLSS under Screen → Anti-aliasing and apply/restart. Linux retains NRD
but does not include the Windows DLSS integration.

This is an unpublished local review package. NVIDIA mark-placement approval
is still pending; attribution alone does not establish that approval. Native
Windows and NVIDIA frame-generation hardware qualification remain outstanding.
See [integration details](../integrations/nvidia-dlss.md) and
[attribution requirements](../branding/graphics-sdk-attribution.md).
Test evidence is in the [validation report](../validation/dlss-restoration-2026-10-24.md).
