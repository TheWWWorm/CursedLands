# Cursed Lands 1.14.0

Windows now defaults to **Automatic** under **Options → Screen → Renderer**. It tests **Direct3D 12**, then **Vulkan**, and finally **OpenGL** in separate processes before loading the 3D menu. The first successful API is remembered; a failed or timed-out probe advances automatically. If the selected API differs from the current one, the game relaunches itself. API changes cannot happen inside a running Godot renderer.

- Keep modern rendering when a test succeeds. Retest after a graphics-driver change or when Automatic is selected again after a manual choice. An interrupted probe is skipped on the next launch.
- Guard the first 3D presentation separately. A small successful test does not accept the full menu; a failed menu presentation advances to another API on the following launch.
- Offer manual Direct3D 12, Vulkan and Compatibility selection, with Safe rendering on Windows. `Play-Vulkan.cmd` and `Play-Compatibility.cmd` provide startup choices before game scripts; Compatibility also selects basic graphics.
- Place recruitment prices, copy counts and trait icons on compact translucent panels with light borders and cost-based accents in Trials and Autochess. Match alliance labels to the panel style and retain thin dark outlines on text and icons. Shop tribe icons glow in their tribe color when that tribe is represented in the deployed army; the indicator follows your own army while scouting. ([#15](https://github.com/TheWWWorm/CursedLands/issues/15))
- Increase one- and two-star banshee health by 30% and attack playback/cadence by 50% in Trials. The final dark banshee retains its existing values. Increase two- and three-star red harpy fire-wall power from 40/50 to 80/140 and fire-arrow power from 28/35 to 56/98. These changes apply to recruited creatures on both sides in Expedition and Autochess; campaign creatures retain their original values. ([#15](https://github.com/TheWWWorm/CursedLands/issues/15))
- Translate new settings, choices, help and test status into English, Russian and German. Keep the first-person action setting from 1.12.0.

The detector requires the initial 2D game window to open. Native capability fallback handles unsupported APIs before scripts. A driver failure that freezes the entire operating system still requires a system restart; the saved test journal chooses the next API afterward. Compatibility uses fewer effects. The unpublished 1.13.0 candidate is superseded by this release; its tag and artifacts are unchanged.

Campaign saves, settings, existing Trials armies and documented mod interfaces remain supported. Co-op retains protocol **23** and requires matching game versions. Original game data is required and is not included.
