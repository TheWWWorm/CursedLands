# Cursed Lands 1.1.1

- Offer the previous session's crash report before intro movies and 3D menu loading, so its save and clipboard controls remain accessible during repeated menu-load failures. ([#3](https://github.com/TheWWWorm/CursedLands/issues/3))
- Show a pending renderer recovery notice after the crash report and before startup continues.
- Add checkpoints around intro playback, loading-screen creation and 3D menu construction to diagnostic logs.

This is a patch release under the [versioning policy](../versioning.md).
Existing campaign saves, network characters, settings, mod profiles, Mod API 1
and texture Package API 2 remain supported. Co-op uses **network protocol 23**.
All players should use 1.1.1; mixed-version sessions are unsupported.

After an unexpected exit, reopen the game and choose **Save report** before
continuing to the menu. On Android, the report is saved to **Download** when
available; the dialog shows the saved location. **Copy to clipboard** is also
available. This update improves diagnostic access; it does not establish or
resolve the cause of a device-specific native crash.

Downloads cover Linux x86-64, Windows x86-64, macOS universal, Android ARM64,
the browser export and the mod-tools bundle. The hosted browser build includes
the same changes. Bring your own original game data; original game files,
player saves and third-party mod assets are not bundled.

Validation and platform limits are recorded separately in the
[release validation record](../validation/stable-1.1.1-2026-10-14.json).
