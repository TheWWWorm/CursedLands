# Cursed Lands 1.13.0

Windows now offers **Compatibility (OpenGL)** and **Forward+ (Direct3D 12)** under **Options → Screen → Renderer**. The selected renderer is kept between launches. Labels, choices, restart prompts and help are available in English, Russian and German.

- Start `Play-Compatibility.cmd` from the Windows package to use OpenGL with Safe rendering, basic graphics and automatic detection disabled. This also saves Compatibility for later launches. The startup crash report offers the same recovery choice before loading the 3D menu.
- Use the Safe rendering thread by default on Windows. Diagnostic reports include the actual rendering-thread mode.
- Keep renderer-trial fallback active until the 3D menu has been presented. Waiting on startup notices, backgrounding or exiting before that point does not confirm the trial.

The normal Windows default remains Forward+ (Direct3D 12). Compatibility uses fewer effects. A failure before the engine reaches game scripts still requires the compatibility launcher. First-person action settings from 1.12.0 remain available.

Campaign saves, settings, existing Trials armies and documented mod interfaces remain supported. Co-op retains protocol **23** and requires matching game versions. Original game data is required and is not included.
