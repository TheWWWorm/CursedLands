# 1.20.0-alpha.1 — desktop mod preview

- Add optional Lua formulas for experience rewards, revival duration and revival
  health in single player and campaign co-op. Compose multiple mods in resolved
  package order. ([#50](https://github.com/TheWWWorm/CursedLands/issues/50))
- Add package API 3 with English, Russian and German descriptions and numeric
  settings. Retain API 1 data mods and API 2 texture packs.
- Include Expedition experience, Quest focus and Field medicine as editable
  source examples and importable packages.
- Include declared Lua sources in save and co-op fingerprints. Execute gameplay
  formulas on the authority, discard Lua state after each callback, and block
  simulation, saving and returned progress after a formula error.
- Load the formula runtime only when a formula package is activated.

This preview targets Windows/Linux x86-64. Formula mods are unavailable on
Android, macOS and the browser. Original multiplayer, persistent script state,
arbitrary engine hooks, original-game DLL support and DLL conversion are outside
this preview. Existing saves and profiles remain compatible; preview co-op peers
must use the same build and matching gameplay mods. Network protocol remains 23.

Read the [player guide](../mods.md), [authoring guide](../mod-formulas.md) and
[validation record](../validation/mod-formulas-1.20.0-alpha.1.md).
