# Cursed Lands 1.0.4 Feedback 5

Includes the campaign, co-op, direct-control and optional HD texture support
from Feedback 4, with the following changes:

- Open Mods and rules directly from the main menu. Installed mods and downloads
  share one page, with labelled On/Off switches and a single Apply & restart
  action. Enabling mods from Original saves creates a separate profile.
- Use compact profile controls and correctly scaled dropdowns. Russian and
  German labels describe profile switching, installation and activation.
- Preserve interface coordinates when HD textures replace the original sheets.
  HUD frames, bars, tutorial buttons, camp controls, map controls and dialog
  borders use the correct parts of the larger textures. Settings buttons keep
  their border thickness and stone grain at the original interface scale.
- Keep the head and hair attached together when smoothing a character's limbs.
  The portrait-head option remains active in direct-control views.
- Clip nearby parts of the controlled body around the first-person camera,
  keeping the animated neck and torso clear of the stabilized view.
- Play every lighting stage of the launch loading screen before opening the
  main menu in both Evil Islands and Lost in Astral.

Protocol remains 21. Co-op peers should use the same build. Existing saves,
installed texture packs and Mod API 1 remain supported; package API 2 accepts
texture packs only. The download catalogue currently supports HD Lands for the
base campaign on Linux and Windows. Game data and downloaded mods are separate
from the application packages.

Validation is recorded separately in `docs/validation/ui-hd-followup-2026-10-12.json`.
