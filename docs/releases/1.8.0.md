# Cursed Lands 1.8.0

Stable release following 1.7.0.

- Rework the website and in-game encyclopedia with clearer search results, category artwork and readable article layouts in English, Russian and German.
- Connect items to their acquisition sources and uses, and open related encyclopedia articles from gameplay panels.
- Add practical mechanics guides, quest guidance and interactive maps with nearby detail popups, optional creature markers and directional exits.
- Compare Easy and Hard creature statistics alongside the game rules that produce them.
- Add character planning and camp-style item and spell construction, including materials, enchantments, compatible runes and equipment slots. Preserve complete builds in shareable links.
- Save named items, spells and characters locally, reopen them from Saved creations, and reuse saved recipes in compatible selectors.
- Place searchable item and spell selectors beside the camp on wide screens. Keep both panels the same height and their selected-item actions visible while results scroll.

This is a backward-compatible minor release under the [versioning policy](../versioning.md).
Existing campaign saves, network characters, settings, Mod API 1 and texture
Package API 2 remain supported. Co-op uses **network protocol 23**; all players
must use the same build.

Downloads cover Windows and Linux x86-64, Android ARM64, macOS universal and the
browser export. The [hosted game](https://cursedlands.wwworm.com/) and
[public wiki](https://cursedlands.wwworm.com/wiki/) use the release source.
Playing the game requires your own original game data; the public wiki does not.

Browser and native saved-creation libraries are local and separate. Share links
transfer builds between them. Wiki construction calculates recipes without
changing a gameplay inventory or save. The website character portrait is
illustrative; character totals exclude equipment bonuses, perks and temporary
effects. See the [wiki guide](../wiki.md).

Runtime and rendering validation ran on Linux. Windows and macOS packages are
exported and audited without native OS runtime tests; macOS is unsigned.
Android retains the production signing certificate and qualified engine template,
with versionCode 40; no new on-device gameplay run is claimed. Browser checks
cover startup, service-worker upgrades and the public wiki, rather than a full
campaign. See the [release validation](../validation/release-1.8.0-2026-10-16.json).
