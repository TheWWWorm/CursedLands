# Cursed Lands 1.0.4

Stable 1.0.4 consolidates the 1.0.4 previews and adds dialogue, controls, save-management and rendering fixes.

- Highlight characters with available conversations using the same material effect as character selection.
- Keep the Lost in Astral smith's completed Assortment introduction separate from his purchase catalogue. Add a Back entry and retain all authored offers.
- Display localized rune reward and wand blueprint names in dialogue, tooltips and item details.
- Use **Q** to open and close quests in first- and third-person views; **Tab** toggles the pointer. The quest key is configurable, and existing custom bindings are retained.
- Choose co-op host saves and client heroes from scrollable dropdowns with save names and dates.
- Copy compatible original campaign saves, metadata and thumbnails when creating a mod profile, including automatic profiles created when enabling mods. Later profile switches retain the copied campaign's progress.
- Keep camera-centred rain and snow out of mirror-water reflections.

This release also includes the preview work on first- and third-person movement and attacks, F6 camera cycling, hold-Ctrl prone controls, character shapes and previews, spell targeting, footprints, co-op synchronization, scripted mechanisms, mod profiles and rules, and the optional HD Lands texture download. See the [changelog](../../CHANGELOG.md) for the individual changes.

Downloads cover Linux x86-64, Windows x86-64, macOS universal and Android ARM64, plus the mod-tools bundle. Bring your own Evil Islands or Lost in Astral data. Original game data, player saves and third-party mod assets are not bundled.

All co-op peers must use this build together: **network protocol 21**. Existing campaign saves and **Mod API 1** remain supported. **Package API 2** supports texture packs; broader legacy scripts, maps and gameplay mods still require a port. The optional HD Lands download is available for the base campaign on Windows and Linux.

Validation is recorded separately in the [release validation record](../validation/stable-1.0.4-2026-10-13.json). Windows and macOS are cross-built and package-audited; macOS is unsigned and not notarized. Prior Internet/ZeroTier performance and Realme compatibility limits remain applicable. This release does not represent a complete campaign playthrough on every platform.
