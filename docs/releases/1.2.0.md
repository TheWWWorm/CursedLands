# Cursed Lands 1.2.0

- Ask before running graphics checks on handheld devices. **Run check** starts the test; **Skip** keeps the initial Original graphics settings or preserves existing manual choices. The prompt explains that, in case of a crash, reopening the game restores Original graphics. ([#3](https://github.com/TheWWWorm/CursedLands/issues/3))
- Start the first handheld menu with Original graphics and a 30 FPS limit. Wait for startup screens to close before offering automatic graphics detection.
- Restore Original graphics and disable automatic retries after an interrupted handheld graphics check.
- Add **Use basic graphics** and **Test startup graphics** to the startup recovery screen. The optional startup test records separate rendering stages for the loading screen, menu scene and interface.
- Stop rendering hidden interface previews and resizing their inactive viewports.
- Translate the new prompts, actions and recovery notices into Russian and German.

This is a minor release under the [versioning policy](../versioning.md).
Existing campaign saves, network characters, settings, mod profiles, Mod API 1
and texture Package API 2 remain supported. Co-op uses **network protocol 23**.
All players should use 1.2.0; mixed-version sessions are unsupported.

After an unexpected exit, reopen the game to save or copy the previous session's
report before continuing to the menu. On Android, **Save report** uses **Download**
when available and shows the saved location. **Use basic graphics** applies
Original graphics; **Test startup graphics** offers the optional staged check.

Downloads cover Linux x86-64, Windows x86-64, macOS universal, Android ARM64,
the browser export and the mod-tools bundle. The hosted browser build includes
the same changes. Bring your own original game data; original game files,
player saves and third-party mod assets are not bundled.

Validation and platform limits are recorded separately in the
[release validation record](../validation/stable-1.2.0-2026-10-14.json).
