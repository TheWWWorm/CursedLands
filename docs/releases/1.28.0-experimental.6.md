# 1.28.0-experimental.6 — Vegetation preparation and scene uploads

Local preview based on stable 1.27.0, retaining the PT, NRD history, adaptive
resolution, nearby grass shadows and DLSS presentation changes from
experimental.5. Network protocol 23, formula API 1 and package API 3 remain
unchanged; use matching builds for co-op.

- Prepare streamed biome ground-cover layouts before play, including the
  additional vertex channels used by stones and aquatic cover.
- Prepare Mirror-water pipelines with the reflection viewport's actual
  multisampling and fog settings during zone loading.
- Upload replacement ray-tracing texture arrays over several frames. Keep
  the previous scene visible until every layer, mip and acceleration structure
  is ready. Cancellation and failed uploads discard only the private candidate.
- Include resource-stage and upload-step timings in diagnostic reports.

This is an unpublished local preview. Native Windows frame pacing remains
pending; Proton presentation counters do not qualify Windows pacing.
SDK files, optional-mod licenses and attribution are retained.
