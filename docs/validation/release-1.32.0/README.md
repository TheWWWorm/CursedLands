# Release 1.32.0 candidate validation

The release record in the parent directory identifies the tested candidate game tree, package hashes, platform scope and limits. Linux packaged tests cover gameplay, menus, Autochess and path tracing. GPU Lab supplied isolated displays and muted profiles; Windows/D3D12 cases ran through the registered Proton runtime with one locked writable prefix. All five exports contain the same 453 compiled game scripts.

The Autochess hover test originally moved only a synthetic pointer while the virtual display's real pointer remained elsewhere. Two 1080p runs and the 1440p and 4K runs failed the unchanged hover assertion. A trace showed the real pointer at the display centre, outside the badge. The repaired test synchronizes that pointer, verifies the badge remains hovered, and retains the original hover check. The same strengthened fixture with synchronization removed fails both checks; diagnostic logs are retained. Its original game comparison is inapplicable because Autochess is a remake mode.

The verbose utility-glyph test produced a truncated CLI tail that omitted the suite-start record. The original runner's unchanged verdict applied to the complete job log passes all 303 checks. Both the original failing runner result and the full log are retained. A Windows RR test initially ran under managed player presets while trying to change hidden diagnostic settings; six checks failed. The same fixture passes all 38 checks with the documented `--ei-pt-tuning` switch. Separate tests exercise the managed preset and Apply/Cancel behavior.

Full-resolution candidate captures are retained under the workspace's `Evidence/releases/1.32.0`; the manifest records dimensions and hashes. Update-check screenshots use a simulated 9.0.0 version. Browser tests cover a fresh start and the service-worker upgrade from the published 1.31.1 archive while preserving storage. Native Windows, macOS and Android device runtime limits, and outstanding reports, are stated in the release record.
