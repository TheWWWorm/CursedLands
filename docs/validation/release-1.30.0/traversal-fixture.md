# Traversal fixture navigation

The first registered Gipat river route failed one of 50 assertions: walking leg 2 ended only 0.434 m from its start. Its trace shows three nearby actors (5105, 5106, 5107), three attempted reroutes, all 362 frames controllable with PT/native NRD active, advancing world time and inputs being acknowledged. The following leg moved 17.221 m. An unchanged repeat then failed to select leg 2 at all and stopped after 35 checks. Both failures and their diagnostics are preserved; neither counts as an accepted run.

The fixture called the route-search version of `NavGrid.direct_line`, which includes coarse standing-actor stamps. Production continuous keyboard steering instead checks terrain separately and uses body sweeps that permit motion out of an overlap. A targeted assertion added to the existing deterministic authority-movement test reproduced the mismatch on loaded original terrain: the old fixture returned no goal while the real controller could back away. It failed all three new escape assertions (44 checks total), then passed all 44 after the fixture correction.

Goal selection now uses the same terrain/body separation as the controller. The full proposed segment must pass the body sweep, so selecting a route through another actor remains prohibited. The rendered river and snow cases are rerun with their original 50-check minimum, per-leg displacement, 12-second phase duration, live AI, collisions and PT/NRD/control checks unchanged. No neutral diplomacy, teleportation, reduced assertion threshold or game-source change was used to obtain acceptance.

The initial trace is consistent with crowd interference; the confirmed defect is the fixture's inability to choose a physically valid escape from an actor stamp. The navigation grid and direct controller are unchanged from 1.29.0, and the unit changes in this release do not alter continuous movement. Original-game code and Wine comparison are inapplicable to this test-only route selector for the remake first-person camera. Its behavior is checked against the existing production controller, with the registered authority movement regression exercising collision, overlap escape and normal input behavior.
