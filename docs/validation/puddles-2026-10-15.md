## Puddle appearance

The previous small texture repeated at regular world-space intervals. A larger,
rotated noise field now varies the sampling position and depression depth. It
uses the existing texture/sampler, with one additional texture lookup only on
eligible wet ground. Dry, disabled, steep and grass-covered pixels skip it.
A muted sky sheen keeps the pools visible from above; Compatibility converts
its sampled ground colour before blending so its contrast matches Forward+.

The actual original/HD terrain captures cover full wetness after rain stops,
partial drying, dry ground, the option off, steep/isometric and shallow views,
and an artificial roof. Puddle-off and dry comparisons remain pixel-identical.
Visible changes affect about 2% of the 800×600 frame, retaining sparse coverage.

These image counts test visibility, not physical water coverage. Captures were
visually reviewed for variable sizes, uneven placement and restrained colour.
The 4K GPU comparison in the JSON record changes only the puddle mask in the
same terrain shader, with repeated runs and shader warmup. It is not a total
FPS benchmark and does not represent Windows or a laptop GPU.

## Belt weight

The native weight calculation already included belt items, but belt transfers
left its cached value stale. Transfers and consumptions now update that value
before syncing inventory. Guest changes use the existing short wall-clock
menu-update batch, including while the simulation is paused.

The actual camp UI/ENet fixture passes 72 checks in each campaign. It covers
host, guest and offline transfers, two different charge states, removing an
already-equipped wand, the visible weight row, consumable removal and unchanged
health, stamina, models and live combat modifiers. The pre-fix control fails
23 of its original 60 checks; the final fixture adds pre-equipped removal.
The existing training-latency regression also passes.
